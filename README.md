## 📌 About the Simulation

Deloitte's Cyber practice helps organizations anticipate, withstand, and recover from cyber incidents. In this job simulation, I worked through a realistic client scenario — investigating suspicious activity on a company's systems using web-activity log data, guided by pre-recorded videos and example answers from real Deloitte professionals.

## 🎯 What I Did

- **Task 1 — Identify Cyber Threats:** Reviewed a client's web-activity log file, established a baseline of normal user behaviour, and flagged suspicious IP addresses and sessions that deviated from it.
- **Task 2 — Investigate the Breach:** Traced the flagged activity to determine whether it originated internally or from an external attacker, and evaluated whether external access was possible without VPN credentials.
- **Findings Summary:** Documented the investigation outcome and recommendations in a clear, client-ready write-up.

## 🛠️ Skills & Concepts

- Log analysis & baseline behaviour modelling
- Anomaly / pattern detection
- IP address and session investigation
- Internal vs. external threat attribution
- VPN / access-control evaluation
- Client-facing technical reporting
